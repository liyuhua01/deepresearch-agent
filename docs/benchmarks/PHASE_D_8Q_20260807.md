## 解读边界

1. **工程完成能力通过首轮验收。** 8 题全部完成，无配置、规划、模型、报告或客户端超时失败。
2. **搜索主路径很不稳定。** 33 次受记录的搜索尝试中 32 次失败；16 次降级全部恢复，因此最终任务仍全部完成。这证明降级机制有价值，也说明不能只报告最终完成率。
3. **引用可访问性达到初始目标。** 加权可访问率 85.51% 高于 80% 初始门槛。
4. **引用覆盖仍是主要短板。** 加权覆盖率只有 43.93%，Q03 为 0%，Q07/Q08 也低于 11%。这一指标只表示结论附近是否有引用，不代表引用在语义上真正支持结论。
5. **尚不应声称“引用支持率”。** 当前已自动化可访问率和覆盖率，但语义支持率仍需要人工抽样或 LLM-as-judge（用独立模型按固定规则判定证据是否支持结论）评测。
6. **费用数据仍缺口径。** Token 是供应商返回的真实值，但未配置模型价格表，因此费用保持为 `null`。
