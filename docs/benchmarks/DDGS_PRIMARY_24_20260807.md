# DDGS 主搜索路径 24 次可靠性回归（2026-08-07）

## 目的

验证将 DDGS 多引擎适配器从 DuckDuckGo 降级路径提升为主路径后，是否消除首轮 Agent 评测中 `32/33` 的主搜索失败。

## 设置

- 代码状态：`ee3c2be` 之后的本地未提交候选改动。
- 题目：`backend/benchmarks/questions.json` 固定 8 题。
- 重复：每题 3 次，共 24 次。
- 配置：`search_api=duckduckgo`、`fetch_full_page=false`。
- 范围：只调用 `dispatch_search()`，不调用 LLM，不生成报告。
- 成功：返回至少 1 条结构化结果。

## 结果

| 指标 | 结果 |
|---|---:|
| 搜索运行 | 24 |
| 成功 | 24/24（100%） |
| 空结果 | 0 |
| 主搜索失败 | 0/24（0%） |
| 备用路径触发 | 0 |
| 每次最少结果数 | 4 |
| 平均耗时 | 2.846 秒 |
| P50 | 2.545 秒 |
| P95 | 4.864 秒 |
| 最大耗时 | 6.219 秒 |

DDGS 内部个别搜索引擎仍可能失败，例如本次多次出现 Wikipedia TLS 错误或 Mojeek 403；但 DDGS 的其他引擎继续返回结果，因此应用层 24 次主搜索全部成功。这正是采用多引擎适配器作为主路径的原因。

## 结论边界

- 本结果支持“DDGS 主适配器在固定题搜索级回归中为 24/24 成功”。
- 本结果不能替代完整 Agent 的 8 题 × 3 次评测，也不能证明搜索结果相关性、引用支持率或最终报告质量。
- 下一步仍需把候选代码部署到独立预发布服务，在相同模型与来源溯源配置下运行完整 24 次 Agent 回归。
