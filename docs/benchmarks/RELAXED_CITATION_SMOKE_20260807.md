最终报告按核心洞见和主题段落提供 `[1](URL)`～`[5](URL)` 数字引用，同一段中的多句话共用段尾来源；背景、风险和已在前文标注的内容没有机械重复逐句引用。参考来源章节保留了同一套数字编号，编号与 URL 一致，5 个 URL 均来自本次来源目录且可以访问。

这次结果符合新的宽松口径：重点看相关资料是否真实进入模型上下文、最终 URL 是否可追溯和可访问，不以逐句引用覆盖率作为通过门槛。当前 5 个来源均为一般网页，权威来源数为 0，因此 100% 相关率不能解读成权威性或逐句语义支持率。

## 试跑暴露的性能问题与修复

报告正文和参考来源区正常复用了相同 URL，产生 15 次原始引用、5 个唯一 URL。旧逻辑仅因重复率高于 50% 就触发一次报告质量重写，使 reporting（报告生成）阶段达到 90.138 秒。

后续提交 `e5041b3` 已把重写条件收紧为“重复率超过 50% 且最大单一来源占比超过 35%”同时成立，来源多样、仅在正文和参考区各出现一次的情况不再额外调用 LLM。本地 86 项测试已通过；由于当前环境到 GitHub 443 端口连续超时，该提交尚待推送和二次预发布计时复验。
