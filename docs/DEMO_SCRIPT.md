# 45 秒演示脚本

## 录制前

- 提前访问一次公开链接，避免把免费实例冷启动录进去。
- 使用固定题目 5 或 8，提前确认当日额度和模型余额。
- 浏览器缩放到能同时看见任务清单、研究进度和来源列表。
- 关闭包含 API Key、个人账号、通知和书签的页面。

## 分镜

| 时间 | 画面 | 旁白/字幕 |
|---:|---|---|
| 0–5s | 输入固定研究题，点击开始 | “这是我工程化改造并部署的深度研究 Agent。” |
| 5–15s | 展示任务自动拆解和实时进度 | “它把问题拆成可追踪任务，并通过流式接口持续返回状态。” |
| 15–28s | 展示检索来源、摘要和工具记录 | “每个阶段保留来源和中间证据，失败也会给出明确错误。” |
| 28–38s | 快速切到最终报告和引用 | “最终报告由多轮检索汇总，并提供可点击引用。” |
| 38–45s | 展示 README 架构图或评测表 | “部署层还加入密码、限流、每日预算、取消和固定题回归评测。” |

如果研究生成时间超过 45 秒，可先完整录制，再把中间等待段加速；不要伪造结果。视频描述中注明模型、搜索源和录制日期。
